# Agentic SDLC Pipeline (Claude Code)

An 8-stage Agentic SDLC ecosystem: requirements → architecture → design review → implementation planning → implementation → code review → verification → PR.

## Quick start

```bash
git init
chmod +x .claude/scripts/*.sh
# create user-story.md, then in Claude Code:
#   "Run the full SDLC pipeline for the user story in user-story.md"
```

See `docs/setup-and-usage.md` for details.
