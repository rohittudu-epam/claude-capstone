Product Overview\n\n### Vision\n\nLinkNote is a privacy-friendly personal knowledge management application that helps users create Markdown notes and discover meaningful relationships between them through automatically generated, user-approved link suggestions.\n\n### MVP Scope\n\nThe MVP covers the complete workflow:\n\n- Local development and deployment setup (Docker Compose, CI)\n- Authentication (registration, login, JWT access/refresh tokens, session management)\n- Note and tag management (CRUD, ownership, soft delete)\n- Full-text search (PostgreSQL FTS, tag filtering, user isolation)\n- Asynchronous link discovery (Redis Streams events, keyword-based similarity, background analysis)\n- Bidirectional links (accept/reject suggestions, canonical relationships)\n- Interactive knowledge graph visualization (2D force-directed graph, tag filtering)\n\n### Out of Scope (MVP)\n\n- Public subgraph sharing\n- File attachments\n- Advanced vector / semantic search\n- 3D graph visualization\n\n### Stakeholders\n\n| Role | Interest |\n| --- | --- |\n| End user | Personal knowledge capture, discovery, and visualization |\n| Developer | Reproducible environment, clear contracts, testable code |\n| Security reviewer | Data isolation, no plaintext secrets, token handling |\n| Operations | Health checks, structured logging, deployment verification |\n\n---\n\n## 2.
